MITRE ATT\&CK :

\- Persistence (TA0003)

&#x09;- Boot or Logon Autostart Execution (T1547)



Description:

This detection queries for activity involving Run keys using "PowerShell.exe", "reg.exe", or "cmd.exe".



`event.dataset:("windows.sysmon\_operational" or "endpoint.events.process" or "windows.powershell"  ) and  process.command\_line.text: "Microsoft\\\\\\\\Windows\\\\\\\\CurrentVersion\\\\\\\\" and process.command\_line.text: ("Run" or "RunOnce") and process.name:("powershell.exe" or "reg.exe" or "cmd.exe")`



Description:

This detection queries for creation or modification of the RUN key using Sysmon Event ID 13.



`event.dataset:"windows.sysmon\_operational" and winlog.event\_id: 13 and registry.path : \*Microsoft\\\\Windows\\\\CurrentVersion\\\\Run\*`



Description:

This detection queries for files created in the Startup directory commonly used for scripts. 



`event.dataset :"endpoint.events.file" and event.action:"creation" file.path: (Roaming\\\\Microsoft\\\\Windows\\\\Start Menu\\\\Programs\\\\Startup\\\\) and file.name: (\*.bat or \*.lnk or \*.ps1 or \*.jse or \*.vbs)`
